# Day 5 BNSP - Aplikasi InventarisKu

## 📌 Deskripsi
Pada pembelajaran hari ke-5 BNSP, saya mengembangkan aplikasi sederhana bernama **InventarisKu**, yaitu aplikasi berbasis web untuk mengelola data inventaris barang.

Aplikasi ini dibuat menggunakan HTML, CSS, dan JavaScript. HTML digunakan untuk membuat struktur halaman, CSS untuk mengatur tampilan, sedangkan JavaScript digunakan untuk mengolah data barang, menghitung nilai inventaris, menambahkan barang baru, dan melakukan pencarian data.

## 🎯 Tujuan Pembelajaran
- Memahami penggunaan JavaScript dalam aplikasi web.
- Mengenal penggunaan variabel, array, dan object.
- Memahami penggunaan fungsi atau `function`.
- Mempelajari kondisi `if-else` dan perulangan.
- Memahami cara mengambil dan mengubah elemen HTML menggunakan DOM.
- Mempelajari validasi input dari form.
- Memahami cara mengolah dan menampilkan data secara dinamis.

## 🛠️ Teknologi yang Digunakan
- **HTML** — Membuat struktur halaman aplikasi.
- **CSS** — Mengatur tampilan, warna, tata letak, dan responsivitas halaman.
- **JavaScript** — Mengolah data inventaris dan menjalankan fitur aplikasi.

## ✨ Fitur Aplikasi

1. **Ringkasan Inventaris**  
   Menampilkan jumlah jenis barang, total stok, dan total nilai inventaris.

2. **Tambah Barang**  
   Menambahkan data barang baru melalui form yang berisi kode barang, nama barang, jumlah stok, dan harga satuan.

3. **Daftar Inventaris**  
   Menampilkan data barang dalam bentuk tabel, termasuk kode, nama, stok, harga satuan, nilai stok, dan status barang.

4. **Pencarian Barang**  
   Memudahkan pengguna mencari data berdasarkan kode, nama, stok, atau harga barang.

5. **Status Ketersediaan Barang**  
   Menentukan status barang secara otomatis:
   - **Aman:** Stok 5 atau lebih.
   - **Menipis:** Stok kurang dari 5 tetapi masih tersedia.
   - **Habis:** Stok berjumlah 0.

6. **Perhitungan Nilai Inventaris**  
   Menghitung nilai stok berdasarkan harga satuan dikalikan jumlah stok barang.

7. **Validasi Form**  
   Memeriksa kelengkapan input, memastikan stok dan harga tidak bernilai negatif, serta mencegah penggunaan kode barang yang sama.

8. **Tampilan Responsif**  
   Menggunakan CSS agar tampilan aplikasi menyesuaikan ukuran layar komputer maupun perangkat seluler.

## 📚 Materi yang Dipelajari

- **Array dan Object:** Menyimpan kumpulan data barang beserta informasinya.
- **Function:** Membuat fungsi untuk menghitung nilai barang, memformat harga rupiah, dan menentukan status stok.
- **DOM (Document Object Model):** Mengambil serta memperbarui elemen HTML menggunakan JavaScript.
- **Perulangan:** Mengolah data barang untuk menghitung ringkasan dan menampilkan tabel.
- **Kondisi `if-else`:** Menentukan status stok dan memeriksa validitas data.
- **Event Listener:** Menjalankan fungsi ketika pengguna melakukan pencarian atau mengirim form.
- **Validasi Input:** Memastikan data yang dimasukkan sesuai dengan ketentuan.
- **Manipulasi Data:** Menambahkan barang baru ke dalam array dan memperbarui tampilan aplikasi secara otomatis.

## 📁 Struktur File

- `index-inventaris.html` — Struktur halaman aplikasi.
- `style-inventaris.css` — Pengaturan desain dan tampilan aplikasi.
- `script-inventaris.js` — Logika JavaScript untuk mengolah data dan menjalankan fitur aplikasi.
